# ELÉTRICAI — CALCULATION ENGINE (DOCS)

### 1. Fórmulas Normatizadas
* **NBR 5410:** Capacidade de condução de cabos (tabelas 36-39), fatores de temperatura e agrupamento, queda de tensão máxima admissível.
* **IEC 60909:** Curto-circuito simétrico trifásico, impedâncias de transformadores e cabos.
* **Critério de Sobrecarga e Curto Térmico:** $I_b \le I_n \le I_z$, $I_2 \le 1.45 I_z$, $S_{min} = (I_{cc} \sqrt{t}) / k$.

Consulte `/plano_do_eletricai/04_CALCULATION_ENGINE_E_NORMAS.md` para a formulação matemática integral.
